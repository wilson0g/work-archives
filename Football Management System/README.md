# Football Management System

A Java-based football player statistics and ranking system developed using Object-Oriented Programming principles.

## Features

- Register football players
- Store and update player statistics
- Manage different categories of player statistics
- Rank players based on their performance
- Sort and compare player statistics
- Terminal-based interactive menu
- Save player information using file handling

## Object-Oriented Programming Concepts

The project demonstrates several Java and OOP concepts, including:

- Classes and objects
- Inheritance
- Encapsulation
- ArrayLists
- Methods
- Input validation
- File handling
- Sorting and comparison

## Player Statistics

The system manages different types of statistics, including:

- Offensive statistics
- Defensive statistics
- General statistics
- Goalkeeper statistics

## Technologies Used

- Java

## Project Structure

- `WordCupMain.java` – Main program and terminal interface
- `FootballRanks.java` – Manages football player rankings and statistics
- `Player.java` – Represents a football player
- `Offensivestats.java` – Handles offensive statistics
- `Defensivestats.java` – Handles defensive statistics
- `Generalstats.java` – Handles general player statistics
- `Keeperstats.java` – Handles goalkeeper statistics

## How to Run the Project

### Requirements

- Java Development Kit (JDK) installed
- Terminal or command-line interface

### Steps

1. Clone or download the repository.

2. Open a terminal and navigate to the project folder:

```bash
cd "Football Management System"
```

3. Compile the Java source files:

```bash
javac *.java
```

4. Run the application:

```bash
java WordCupMain
```

5. Use the terminal menu to:
   - Register a World Cup player
   - Update player metrics
   - View player rankings
   - Exit the application

## Usage

The program provides a terminal-based interface where users can manage football player information, update performance statistics, and view rankings based on player performance.

## Purpose

This project was developed to apply Object-Oriented Programming concepts in Java by creating a system that manages football player information, tracks performance statistics, and ranks players.
