# Discrete Mathematics Learning Website

A web-based learning platform designed to help students understand introductory concepts in Discrete Mathematics, particularly mathematical logic.

## Features

- Structured learning modules covering introductory logic concepts
- Educational videos for additional explanation
- Examples and visual learning materials
- Interactive JavaScript quizzes after each module
- Immediate assessment to help users test their understanding

## Technologies Used

- HTML
- CSS
- JavaScript

## Learning Content

The website includes topics such as:

- Propositions
- Conjunctions and disjunctions
- Implications and biconditionals
- Logical equivalence
- Truth tables
- Converse statements
- Operator precedence

## Purpose

The project was developed to provide students with an interactive way to learn introductory Discrete Mathematics concepts and evaluate their understanding through quizzes.
